# Gráficos

Complemento privado para analizar datos y preparar gráficas, mapas, redes o representaciones matemáticas. El flujo básico funciona con Node.js y archivos locales. Incluye un tablero interactivo que se abre sin conexión y exportación a Excel, PDF, SVG y CSV. El tablero exporta PNG, además de la opción de rasterizar SVG con un módulo local.

Usa la [habilidad](skills/graficar-analizar/SKILL.md), el [contrato de datos](skills/graficar-analizar/references/uso.md) y las [opciones de motores](skills/graficar-analizar/references/motores.md). Los datos y geometrías del ejemplo son ficticios. El proyecto no requiere cuenta de mapas, Data, Visualize, claves ni créditos de terceros.

[Selección por finalidad y etapa](skills/graficar-analizar/references/seleccion-herramientas.md) orienta qué motor usar. La [escena de rebotes](skills/graficar-analizar/assets/rebotes.html) incluye controles de simulación, vista compatible y capas de demostración de Rapier, Anime.js, Three.js, Postprocessing, PixiJS y Pixi Filters.

[Explorador portátil](skills/graficar-analizar/assets/explorador-portatil.html) abre CSV, TSV y JSON locales, permite filtrar y revisar los registros de cada barra y exporta CSV o SVG desde el navegador, incluso sin conexión.

La [ruta de inteligencia de negocios](skills/graficar-analizar/references/inteligencia-de-negocios.md) combina prácticas de Power BI, Data y Tableau en un flujo propio. Incluye comparación local de KPI y una comprobación descargable del contexto de cada selección del tablero.

Para preparar datos con consultas reproducibles, usa [SQL local](skills/graficar-analizar/references/sql-local.md). Para crear o mejorar una interfaz de análisis, usa [diseño de tableros y visualizaciones](skills/graficar-analizar/references/diseno-frontend.md).

[Revisión SVG](skills/graficar-analizar/assets/revision-svg.html) permite comparar, editar y volver a abrir un SVG y su referencia en un navegador. Aplica el [flujo de verificación de gráficas, mapas y diagramas](skills/graficar-analizar/references/revision-svg.md) para mantener la correspondencia con la fuente de datos.
