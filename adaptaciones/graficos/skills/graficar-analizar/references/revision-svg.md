# SVG editable para gráficas, mapas y diagramas

1. Identifica la fuente de verdad antes de editar. Conserva el cálculo, los valores, unidades, filtros, escalas, denominadores y geometrías aportadas. Trabaja con las filas confirmadas o las formas originales de un mapa o diagrama. Para modificar un dato, cambia el insumo autorizado y vuelve a generar el gráfico.
2. Define el tamaño final y el estilo. Las referencias visuales sirven para la composición, el trazo, la paleta y la jerarquía. Si se necesita una referencia inédita, usa la herramienta integrada, dentro de la cuota del plan y con la regla de cero créditos de terceros. Las posiciones y tamaños que codifican datos se calculan con la fuente, incluso si la referencia ilustra otro estilo.
3. Mantén ejes, marcas, rótulos, contornos y leyenda como elementos vectoriales editables cuando el formato lo permita. Conserva texto y títulos accesibles. Usa el `viewBox` y los márgenes para evitar cortes. Si hay una imagen incrustada, declara qué parte del archivo usa ese recurso.
4. Abre [Revisión SVG](../assets/revision-svg.html). Compara a tamaño de entrega y, si se usará en un teléfono, comprueba una vista estrecha. Recorre ejes, leyendas, etiquetas y contornos. Verifica al menos un valor y su posición o tamaño contra el cálculo original. Prueba una edición de estilo y confirma que los valores, el orden y la escala sigan correspondiendo al insumo.
5. Entrega el SVG editable y, si corresponde, su PNG del mismo tamaño junto con la fuente usada. Compara los bytes reales de ambos. Simplifica detalles decorativos redundantes si el SVG crece. Conserva los elementos necesarios para representar los datos y explica los casos en que la editabilidad justifique un archivo mayor.

El visor abre archivos locales sin servicios de terceros. Si la sesión no puede mostrar el archivo, entrega el SVG y marca la comprobación visual como pendiente. Cuando corresponda, revisa por separado la interacción del tablero HTML y los resultados en PDF o Excel.
