# SVG editable para producción audiovisual

1. Define el uso y el tamaño de entrega antes de dibujar. También comprueba el tamaño más pequeño que verá el público. Para animación, identifica qué partes deberán moverse o cambiar de color de forma independiente.
2. Si el usuario aporta una referencia, úsala para trabajar la forma. Si falta dirección visual y hace falta una imagen, usa el generador integrado que esté disponible en el plan, dentro de su cuota y con la regla de cero créditos de terceros. Pide bordes, planos de color y sombras que se puedan reproducir con formas. Si no hay generador, parte de un boceto o de las formas existentes.
3. Construye la silueta, proporciones y solapes. Añade curvas, rellenos, degradados y sombras solo cuando aporten. Mantén los elementos como vectores separados, con grupos e identificadores estables cuando se vayan a animar. Conserva texto editable cuando convenga y detecta cualquier imagen rasterizada que quede incrustada.
4. Abre [Revisión SVG](../assets/revision-svg.html) en un navegador compatible. Carga el SVG y, si existe, la referencia visual. Compáralos en el mismo encuadre y tamaño. Corrige primero el rasgo que más se aleje y comprueba los elementos vecinos. Ensaya un cambio real en una forma, curva o color del fuente, vuelve a abrirlo y verifica que el cambio sea visible.
5. Entrega el SVG y un PNG exportado al mismo tamaño cuando se solicite una vista previa. Guarda el original si se edita un archivo aportado y el encargo permite una salida separada. Compara bytes reales del SVG y del PNG. Si el SVG es mayor, revisa capas redundantes, imágenes incrustadas y precisión excesiva. Explica la diferencia cuando los detalles editables o visuales la justifiquen.

El visor funciona con archivos locales sin solicitar servicios. En una sesión que pueda crear SVG pero no mostrarlo, entrega el archivo y marca su revisión visual como pendiente. La comparación humana sigue siendo necesaria para evaluar fidelidad y acabado. El visor no sustituye el render final en Remotion ni comprueba animaciones completas.
